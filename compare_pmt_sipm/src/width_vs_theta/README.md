The idea of this project is to use the existing files used for the single_muon_prob project in

/storage/gpfs_data/pauger/users/jdejesus/kit/analysis/single_muon_prob/pmt/outputs/csv/adst_dt_pairs_pmt_*.csv

to produce plots of width (ie #1s) vs sec_theta. With this, we aim to see that the number of 1s depends on theta and, therefore, the efficiency must depend on theta.

With this evidence we plan to argue that the efficiency correction in the PMT paper, which was applied without any theta dependence, needs to be revisited and a zenith dependent correction needs to be applied.

The efficiency for PMTs was obtained with lab measurements with very vertical muons (the muon telescope was very separated bc a bunch of strips were stacked together), therefore the efficiency applied for the paper was the worst-case scenario.
